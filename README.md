# Google Summer of Code 2026 - GNU Octave

This repository hosts the development blog for my Google Summer of Code 2026 project with **GNU Octave**.

## Project Details

*   **Project Title:** Add LinearModel and CompactLinearModel objects to the statistics package
*   **Organization:** [GNU Octave](https://www.gnu.org/software/octave/)
*   **Contributor:** [Avanish Salunke](https://github.com/AvanishSalunke)
*   **Mentors:** Andreas Bertsatos, Colin B. Macdonald
*   **Project Portal:** [View on GSoC Portal](https://summerofcode.withgoogle.com/programs/2026/projects/YKFoacXh)

## Abstract

The goal of this project is to implement a robust object-oriented framework for linear regression within the GNU Octave Statistics package. By introducing the `LinearModel` and `CompactLinearModel` classes, we aim to provide deep statistical diagnostics and memory-efficient deployment options, significantly improving Octave's MATLAB compatibility and usability for researchers and data scientists.

## Running Locally

To run this blog on your local machine:

1.  Ensure you have **Ruby** and **Jekyll** installed.
2.  Clone this repository: `git clone https://github.com/AvanishSalunke/AvanishSalunke-gsoc-2026.git`
3.  Install dependencies: `bundle install`
4.  Start the development server: `bundle exec jekyll serve`
5.  Open `http://localhost:4000` in your browser.
